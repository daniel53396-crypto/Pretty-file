# FIXA FILE STORE — Google Login edition

Static website for GitHub Pages with Google/Gmail OAuth through Supabase Auth. First-time Google sign-in creates the user account; each user can access only their own files when the supplied SQL/RLS and private Storage setup are applied.

Read `README_TAMIL.md` for Tamil setup instructions. Never put Supabase `service_role` or Google OAuth client secret in frontend files.
